# Troubleshoot the app

Each row is a symptom someone measured while building the app, with its cause, the fix and the source record. The fix names what to run; run every command from the root of a `metis-app` clone. A cause that names a platform or a tool (iOS, Android, WebKit, Hermes, Yoga, pnpm, Stryker) was measured by the team on the date and device that the source record names, and the source cell is the citation.

To learn how the checks work, read [Develop the app](develop.md); for what the app calls and exposes, read [App interfaces](interfaces.md); for what it is, read [The Metis app](README.md).

## Checks, tests and mutation

| `gate:unit` or `gate:web` is RED with `passed N, floor M: update scripts/test-floor.json` | The floor is exact: the number of tests that passed differs from `scripts/test-floor.json`. A skipped or flaky test also turns the gate red | If you added or removed tests on purpose, set `unit` or `web` in `scripts/test-floor.json` to the new count in the same change, then run `pnpm verify --only unit,web`. Check with `pnpm exec stryker run --mutate "src/shell/Shell.tsx"` | [Source: [Plan B](../../history/plans/2026-10-06-frontend-overview-screen.md), lines 19939 to 19945 of the original; [Cleanup plan](../../history/plans/2026-10-10-frontend-code-cleanup.md), line 999 of the original] |
| Under Stryker the dry run is red for tests that use `localStorage`, `document` or `window`; a `@jest-environment` docblock in the file makes Stryker report `Missing coverage results` | Stryker runs every Jest project in one environment, taken from the top level of the Jest configuration, which is node by default | Keep `testEnvironment: 'jest-fixed-jsdom'` at the top level of `jest.config.js` and put no environment docblock in a test file. | A component test fails in the Web or Node project with `Text strings must be rendered within a <Text> component` | React Native Testing Library renders only in the iOS and Android projects of Jest | Name a render test `*.test.native.tsx`. ## Layout and platform differences in the apps

| Symptom | Cause | Fix | Source |
