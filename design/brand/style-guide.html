Metis, the visual system

One ink, one accent, one paper. The system uses neutrals and type families, an editorial serif logo and hairlines instead of shadows. Values come from tokens.css, shared with the wireframes.

Logo

The i is "intelligence" in the accent colour; its dot is a diamond, the milestone and gate symbol of governance. Built from Fraunces 700 outlines. Clear space equals the height of the e.

Do and don't

Do
  • Show status with colour, shape and words.
  • Use one primary button per area.
  • Use the same metric definition on every screen.
  • Mark actions made through MCP with the square AI avatar.
  • Give every drag or canvas action a keyboard equivalent, such as "Move to…".
  • Keep 13px as the floor for anything a user clicks or reads as content.
Don't
  • Use the violet diamond as decoration outside the logo.
  • Put numbers in Newsreader or Fraunces.
  • Use donut charts for progress; use a meter or a stat tile.
  • Use faint for anything a user must read, placeholders included.
  • Use the focus ring to show selection, or remove it.
  • Show planned features as disabled buttons.
  • Report an error only in a toast.
